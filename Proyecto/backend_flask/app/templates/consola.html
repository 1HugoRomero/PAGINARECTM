Consola de la API de AgroAsesor

Elige un endpoint, ajusta los datos y envía la petición para ver la respuesta real de la API. Los datos de fertilizantes vienen de la guía FAO/IFA Los fertilizantes y su uso (2002) y la normativa de la Resolución SAG 8.651 exenta de 2024, con el cuadro y la página de donde se tomó cada valor.

Información orientativa. La composición es la de referencia publicada; el valor que vale es el que declara la etiqueta de cada producto. La API no recomienda dosis: el requerimiento de nutriente lo indicas tú a partir de tu análisis de suelo o asesoría técnica.
